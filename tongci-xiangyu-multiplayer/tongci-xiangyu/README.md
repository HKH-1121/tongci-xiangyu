# 同词相遇（联机版）

一个手机优先的 H5 多人联机小游戏。2–4 人进入同一房间，每轮看到一组词，同时输入一个联想词；答案相同的玩家获得默契分。

## 已实现

- 创建房间 / 6 位房间号加入
- 2、3、4 人房间
- 每轮 30 秒、60 秒或自定义 15–120 秒
- 满员自动开始，5 轮游戏
- Socket.IO 实时同步玩家状态、倒计时、提交状态和揭晓结果
- 相同答案自动匹配并计分
- 邀请链接、复制房间号
- 手机和桌面浏览器适配

## 本地运行

需要安装 Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

本地测试多人联机时，让同一局域网的朋友访问运行电脑的局域网 IP 地址，例如 `http://192.168.1.10:3000`。跨网络联机需要部署到公网服务器。

## 快速部署到 Render

项目已附带 `render.yaml`：

1. 将本项目解压后上传到自己的 GitHub 仓库。
2. 登录 Render，选择 **New → Blueprint**，连接该 GitHub 仓库。
3. Render 读取 `render.yaml` 后创建 Node Web Service。
4. 部署完成后，打开 Render 提供的 `https://...onrender.com` 地址。
5. 把网站链接发给朋友；创建房间后再分享房间号或房间邀请链接。

如果 Render 当前账户/地区不提供免费实例，按平台显示的方案选择可用实例。免费实例可能在一段时间无访问后休眠，首次打开会有冷启动等待。

## 游戏规则（当前版本）

1. 房间达到设定人数后自动开始。
2. 每轮出现两个词，例如「大海 × 天空」。
3. 每位玩家独立输入一个同时能联想到这两个词的答案。
4. 揭晓前看不到其他玩家的答案；完全相同的答案视为相遇。
5. 与你答案相同的每位玩家为你增加 1 分；共进行 5 轮，按总分排名。

## 当前版本的限制

- 房间和分数保存在服务器内存中；服务重启后，进行中的房间会清空。
- 玩家刷新页面或网络断开后，需要重新加入；当前版本没有账号和断线续玩功能。
- 匹配采用文本完全一致（忽略大小写、空格和常见标点），暂不识别近义词。
- 这是可部署的 MVP 源码，不是已经替你发布到公网的在线网址；跨网络联机需要完成一次托管部署。
